# Functional Graphs and Accessible Reservoir Memory

Reproducibility materials for the manuscript:

**From Functional Graphs to Dense Reservoirs:
Connectivity Concentration and Accessible Memory**

Manuscript prepared for submission to *Natural Computing*.

## Contents

### Supplementary Resource S1

Located in `supplementary/S1/`.

Includes experiments on:
- Functional-graph structure and scaling
- Connection concentration and temperature
- Finite-sample memory
- Matched prediction benchmarks

### Supplementary Resource S2

Located in `supplementary/S2/`.

Includes experiments on:
- Single-node input placement
- Noise-limited memory

Both resources contain experiment scripts, recorded numerical
results, configurations, and reproduction documentation.
