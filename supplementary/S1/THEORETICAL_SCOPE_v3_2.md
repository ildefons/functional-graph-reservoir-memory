# Scope of the v3.2 theoretical additions

1. Proposition on finite positive temperature applies for **fixed finite N, fixed tau > 0**, random independent scores with an everywhere positive continuous density, and generic absolutely continuous scalar input coupling b. The proof uses a nonzero real-analytic characteristic-polynomial discriminant obtained by approaching a signed Hamiltonian cycle with simple eigenvalues.
2. The ideal noise-free full-history *linear* memory identity additionally requires spectral stability, centered independent inputs and exact readout. Generic controllability is not a claim about finite-sample measured memory.
3. The Gaussian/REM relation uses the **triangular array** tau_N = alpha*sigma_a/sqrt(2*log(N-1)) with fixed alpha in (0,1), not a fixed positive temperature. The row participation expectation converges to 1-alpha from the standard REM/Poisson–Dirichlet Gibbs-weight asymptotics.
4. The induced-infinity-norm bound is an exact normalization identity and an **asymptotic sufficient** contraction condition for alpha < 1-s0^2. Failure does not prove instability.
5. At a fixed positive tau, the maximum incoming normalized allocation vanishes in probability as N grows. The zero-temperature functional-graph approximation is not uniform in network size.
6. No new dynamics or predictive experiments were run. The scaled temperature figure replots the previous recorded 100-substrate-per-size allocations.
